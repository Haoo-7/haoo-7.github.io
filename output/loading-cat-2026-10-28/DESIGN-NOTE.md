# 加载动画：黑猫尾巴当进度条

## 方向

2026-10-28 用户在 A 墨水屏开机 / B 三个词点亮 / C 黑猫尾巴里选了 C。
否 A 的理由：大幅黑白闪烁让他眼睛不适（用 Kindle 和用本站都是）。
否 B 的理由：它只是进站片头，不能表达过程，只配首屏。

## 它回答的问题

「还要等多久？」主角是尾巴的长度，不是文字或百分比。

## 构成

- 主角：尾巴。从猫胯部伸出，沿一条 1px 灰线往右长；墨色是已经加载的，灰线是还剩的。
- 陪衬：猫（复用首页那只 Q 版猫的造型，坐在灰线左端），眼睛看着尾巴尖，偶尔眨眼。
- 文字：没有可见文字；`role="status"` 只给读屏读 “Loading”。
- 没有黑闪：进出都在纸色上完成，退场是 3 步 `steps` 淡出，不经过黑色。

## 状态

| 状态 | 画面 |
| --- | --- |
| 很快就好（< 300ms） | 不出现 |
| 首次进站、等待中 | 纸色盖住页面；300ms 后猫和灰线出现，尾巴随真实进度变长，进度停住时尾巴慢慢蹭（不倒退） |
| 站内跳转、等待超过 400ms | 纸色和猫一起分步淡入，之后同上 |
| 加载完成（首次进站） | 尾巴快速补满 → 甩尾尖带回弹 → 慢眨眼 → 尾巴收回、灰线淡出 → 纸 3 步淡出，猫平移缩放落到首页猫的位置（首页猫不在视口时原地蹲一下再淡出） |
| 加载完成（站内跳转） | 甩一下尾尖 → 360ms 落到首页猫的位置，尾巴和灰线起飞时淡掉；内页 240ms 淡出。就绪到可点 ≤ 650ms |
| 超过 8 秒还没好 | 当作完成，走站内跳转的短收尾 |
| 减少动态效果 | 照样显示尾巴长度，不眨眼、不勾尾巴，退场直接消失 |
| 没有 JS / 从 bfcache 返回 | 不出现 |

进度 = 字体就绪 30% + 首屏图片 60%（平分）+ window load 10%。
猫出现后至少停 600ms，避免一闪而过。

## 和现有动效的关系

首页的入场动画（三个词升起、简介淡入）等加载动画开始退场时再播，不在遮罩下面白播。
站内现有的墨水屏 flash 这次不动；要不要整体调弱另问用户。

## 实现与验收（2026-10-28）

- 文件：`src/components/Loader.astro`（SVG + inline 脚本）、`src/styles/loader.css`、`src/layouts/Base.astro`（引入）、`src/scripts/home.ts`（入场和轮播等 `window.__loaderGate`）。
- 加载层露过面时，首页照片不再做入场黑闪；轮播等放行后才计时，第一次换帧不撞上交接。
- 调试参数（只在 localhost）：`?loader=hold&p=0.4`、`?loader=play`、`?loader=play-nav`。
- 实测：交接落点误差 0px，两只猫同时可见 0 帧；390 / 1440 下左右边距差 ≤ 1px；各状态时刻见 `shots-r3/STATES.txt`。
- 独立评审三轮：8 → 8 → 9。第三轮后的三处小改（快速补满、兜底短收尾、残尾早淡）已做。
- 已知：站点原有的横向溢出（页脚尾巴按钮、首页照片）在手机上把布局视口撑到 421px，这次只在加载层里绕过，没修。
- 证据：`shots/`（第一轮）、`shots-r2/`、`shots-r3/`。

## 第五轮：改成毛线球（2026-10-28，用户提议，替代尾巴进度条）

尾巴当进度条被用户否了：拉长的尾巴把 Q 版比例撑坏，尾尖怎么卷都怪。用户提议「毛球走、猫盯着看」，选了毛线球（不是绒毛球）。

- 猫坐在正中，比例和首页猫完全一样，尾巴也是首页那条从线后垂下去的。
- 毛线球（生图后去色，`public/images/loader/yarn.webp`，12KB）从左滚到右，滚过多远就转多少。身后拖出的毛线就是走过的进度，没走到的地面是一行淡灰虚点，右端一道刻度是终点。
- 猫的眼睛和头跟着球转。加载卡住时球慢慢蹭，超过 1.2 秒没动，猫动一下耳朵。
- 首次进站收尾：球碰到刻度往回晃一下，猫转回来看你，停一下，然后落到首页猫的位置。之前的甩尾、慢眨眼、收尾巴都删了。
- 站内跳转：球到头就交接，猫同时转回来。
- 交接时只有猫飞过去，球、毛线和地面跟着纸一起淡掉。
- 调试参数新增 `?loader=play-stall`（走到一半停 2.4 秒，看动耳朵）。
- 证据在 `shots-r5/`。这一轮由主会话自己改，没有委派。
