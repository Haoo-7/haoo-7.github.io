**md2docx-historypaper-skill**

- 一句话：把用 Markdown 写的历史论文转成可以直接投稿的 Word 文件，脚注和引文都会放在该放的位置。
- Why：我第一次让 Agent 按史学期刊的格式排自己的论文，花了大约两个半小时，在 Word 的 XML 里走错了十二次。
- What it does：
  - 按《历史研究》的体例生成 .docx，标题、摘要、正文和字体都按期刊的要求设置。
  - 脚注用 ①② 编号，每一页重新计数，并统一引文格式。
  - 本地开着 Zotero 时，会从文献库里补上缺的页码，补不上的会列出来。
- Built with：Python 3.10+，只用标准库。
- Status：可以用，我自己的论文就是用它排的。

**agent-recap**

- 一句话：让每个 AI Agent 都用同一种方式收尾，说清这一轮做了什么、下一步做什么。
- Why：我在一台电脑上同时用好几个写代码的 Agent，它们结束长回复的方式各不相同。一场长会话下来，我常常说不清刚才发生了什么、接下来该做什么。
- What it does：
  - 给每个 Agent 加上同样的两行收尾：一行总结这一轮，一行写下一步。
  - 找出电脑上装了哪些 Agent，把规则写进它们各自会读的文件，从 CLAUDE.md 到 Cursor rules 都有。
  - 再运行一次会在原处更新；用一条命令就能把它从所有地方删掉。
- Built with：JavaScript（Node），没有依赖。
- Status：可以用，已经支持 30 多种 Agent。

## 给实现方的提醒

- 标题都留英文，所以中文大字字体主要用在文章标题、目录和「下一篇」上；仿宋强调目前没有地方用，先不加载，等以后中文标题需要强调时再接上。
- 首屏介绍中文版是一整句，不再分出灰色的后半句。
- 用户亲自改过的句子（首屏介绍、Work 说明、Writing 预告、History、关于页说明）按原样使用，不要改标点和措辞。
- 邮票名在英文版是斜体衬线；「少数派」「B站」这类中文名不要硬斜，用正体。
- 阅读器屏幕上的标题，中文版用中文标题，比英文的 shortEn 长很多，要检查会不会溢出，必要时截断。
