## 共同决定

白底与墨黑构成主体，保留小面积蓝色，而非满版高饱和色；字号和构图继续大胆，动效不因此取消。第一眼必须认出 Haoo，主动作查看作品。顺序是认识本人 → 作品 → 文字与社交账号。最初三套误将“克制”收窄为纯黑白，下面保留当时记录，最新字符精修纠正这一点。

名字复用已有 Satoshi 700，自托管思源宋体 CN 可变 WOFF2 承担中文短句与阅读内容，主要用 400 字重。字体来自 Adobe 的 Source Han Serif 官方仓库 release 分支；许可保存在 `assets/SourceHanSerif-LICENSE.txt`。不声称所有系统宋体都有问题，也不把思源宋体称为系统宋体的补丁；这次只改变具体字族并看真实屏幕效果。

白底 `#FCFCFC`，墨黑 `#181818`，辅助字 `#656565`，分隔 `#D4D4D4`。无衬线与衬线对比为共同语法；零字距，无阴影、无圆角卡片、无渐变或炫彩装饰。窄屏使用明确字号档位，不用视口单位缩放字体。

用户提供的 jiejoe 页面可打开，但取证停在加载屏且有未加载图片，不能据此声称其完整页面或滚动已拆解。本轮仅借用户明确认可的大字与力度，不复制其荧光绿。

## 方向卡

### 01 巨字开场

- 北极星：名字就是舞台，滚动后把舞台交给作品。
- 调性：高分量、低饱和、疏排版、精确、庄重但可探索。
- 标杆与取舍：保留第一轮 ansyn 的白底与尺度反差，不沿用散落关键词。个人身份由一个名字承担。
- 生成引擎：个人字标作为可变尺度的品牌资产。
- 首屏线框：固定导航约 80px → 通栏名字约 45% → 中文短句与查看作品约 15% → 首件作品标题露出约 10%。
- 结构：满版文字；名字缩为导航标识后，作品图通栏展出，文章改为阅读列表。
- 字体：Satoshi 700，桌面名字 320px；思源宋体 400，短句 32px、文章标题 22px、正文 18px。
- 主视觉：字标；作品区放本次新首页的真实截图。
- 控件：下划线文字动作与 Lucide 图标；按下位移 2px；键盘焦点有黑色轮廓。
- 三处基本动效：主动作按下反馈并滚到作品；关于面板从右侧滑入；名字、短句、动作在 600ms 内依次出现。
- 滚动分镜：首屏约一屏内名字从 320px 视觉尺度收至 82px 宽的导航标识；作品图从下向上揭开；文章按阅读顺序横向展开一次。没有滚动劫持或重复出场。
- 结构性突破：首屏与导航共用同一个名字，不用独立大口号。
- 记忆点：巨字收入导航，作品接力。
- 放弃：随机代码背景、反复出现的 Logo、介绍性长段落。

### 02 错落书页

- 北极星：阅读一个人的名字，如翻开一本排版大胆的个人刊物。
- 调性：同一黑白身份，构图更实验，信息仍少。
- 标杆与取舍：保留个人站的大字基线，但不沿用左右图文 Hero。
- 生成引擎：名字的两行排字与书页中轴偏移。
- 首屏线框：单行导航 → 左上 Ha → 右上中文短句 → 右下 oo. → 下沿作品入口与黑色作品章节露出。
- 结构：错落文字；第二章成为通栏黑色作品展台；文章是双栏目录而非 01 的通栏列表。
- 字体：同一字体与配色，名字 240px，中文短句 32px。
- 主视觉：Ha / oo. 的位置关系，不添加独立插画。
- 控件：线性文字动作；关于面板从上方展开，不复用第一套右抽屉构图。
- 三处基本动效：主动作按下与跳转；上方关于面板展开；两个名字片段与中文依次到位。
- 滚动分镜：两个字块向内收拢、缩小 18% 并让位；黑色作品章节内图片从左向右揭开；文章目录从右侧展开一次。
- 结构性突破：两行错落名字，中文进入其留白。
- 记忆点：白色名字书页切换到黑色作品章节。
- 放弃：独立装饰纹样、传统居中大标题、与名字竞争的其他巨字。

### 03 作品先行

- 北极星：名字认路，作品负责吸引。
- 调性：同一黑白气质，较紧凑，内容优先。
- 标杆与取舍：沿用作品集首屏应看见作品的基线；不设置整屏身份封面。
- 生成引擎：单件作品展览与出版物题头。
- 首屏线框：名字与中文约 18% → 作品目录一行 → 作品图约 50% → 作品名与入口 → 下一段文字露出。
- 结构：首屏就是作品；文章以题头加目录呈现；黑色页脚作为结束。
- 字体：同一字体，名字 110px，短句 22px，作品名 30px。
- 主视觉：作品截图，不是泛用抽象素材。
- 控件：文字入口与箭头；关于面板在画面中间出现。
- 三处基本动效：进入作品动作按下与滚到项目说明；关于面板浮入；名字先到、作品图紧随揭开。
- 滚动分镜：作品图随约一屏滚动由 1 拉远至 0.8，同时向上 24px；文章目录依次出现；页脚社交入口从下沿到位。图片从完整可见的状态开始，不先裁掉作品边缘。
- 结构性突破：取消大型 Hero，首屏直接交付一个完整作品。
- 记忆点：作品图的拉远比 Logo 动画更重要。
- 放弃：长首屏、作品缩略卡片网格、满页都在讲设计理念。

## 内容与边界

三个方案使用同一内容集：Haoo、现有口号、当前个人站、两篇真实文章与现有社交平台。当前网站小样的真实截图临时承担作品图，不假装已经有经用户挑选的正式作品集。正式首页应换成用户的真实代表项目；此轮是构图决策，不会因项目资料缺失阻塞。

GSAP 3.14.2 与 ScrollTrigger 从固定版本下载到 `vendor/`，保留库头部的版权与许可指向。Alpine 使用 Skill 自带文件。Lucide 图标从官方仓库下载；本轮不引入新项目框架和依赖配置。

减少动态效果时不缩放、不固定主视觉，文字与图片直接显示，按钮与原生 dialog 仍可用。

## 字符巨字精修（2026-10-10）

用户喜欢 ansyn 的字符材料、大字、蓝色与滚动表现，明确要求克制不能等于无动效或纯黑白。本轮保留 01 的构图与阅读顺序，新建 `04-character-name.html`，与原版在 `character-explorer.html` 对照，不替换正式站点入口。

### 视觉与分镜

- 纸张 `#FCFCFC`、墨黑 `#181818`、辅助灰 `#656565`、线条 `#D4D4D4`，恢复蓝色 `#2456D6`。蓝色用在句点、少量字符、主要入口与编号，不增加满版色块。
- 用真实 Satoshi `Haoo.` 字形生成 Canvas mask，再以 `0 / 1 / { } / < > / ; =` 填充。字符组成姓名本身，不另加代码墙。中文继续用思源宋体 CN。
- 入场：字符由小幅散开聚成姓名，短句与入口随后出现，约 550ms 完成。指针：经过姓名时附近字符轻微避让、变蓝，离开恢复，不持续随机闪烁。
- 滚动：在首屏约一屏的距离内，字符逐渐淡出、同字形实心文字显现，姓名缩为 82px 宽的导航字标；短句先淡出避免碰撞，作品接力。回滚按相同路径恢复，没有接管滚轮。
- 作品图沿垂直方向揭开，文章列表沿阅读顺序横向错时出现，一次触发；关于侧栏和主要入口延续原有反馈。
- 390 与 320 宽保持一行姓名；精修后减少约 80px 首屏高度，单字符颗粒增大，缩短姓名至口号的空白。没有通过拆成两行或负字距强行塞入。
- 减少动态效果时姓名正常随页面滚走，不做缩放或指针避让，区块直接显示。`?motion=reduce` 用来直接复现同一分支；尚未单独模拟操作系统媒体偏好切换。

### 单张预览初始化修复（2026-10-10）

用户反馈单张手机预览的姓名与口号为空。比较器会预先在隐藏容器中挂载单张 iframe；原字符脚本没有处理零尺寸布局，生成 mask 时可能读取零宽高 Canvas，中断初始化并留下隐藏的首屏。

`vendor/character-name.js` 现在等待 ResizeObserver 取得有效宽高再初始化；后续隐藏时不清空画布、不重新读取零尺寸 mask，显示或切换视口后再重绘。已重新生成 `character-explorer.html`，不修改 Skill 安装目录或正式站点。

`character-preview.test.cjs` 在隔离的 Node DOM 模拟中覆盖隐藏后显示、显示后隐藏/尺寸变化、减少动态分支；连续三次执行，各次 3/3 通过，语法检查通过。当前浏览器工具拒绝访问 file 协议页，未绕过限制，故本次不宣称真实单张画面已重新验收。此前只验证并排页与独立候选，不能据此证明单张隐藏挂载流程正常。
