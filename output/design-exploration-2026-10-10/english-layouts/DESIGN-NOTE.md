# 04 · 英文动态目录

状态：01「姓名星座」已选定，进入关键交互修复、实际取证与独立评审。版式选择已结束，下一阶段为完整英文首页，然后中文适配。不覆盖上一轮中文页面，不更换正式入口。

## 任务与基线

品类是个人博客与作品入口，主要路径为认识 Haoo → 浏览作品 → 阅读文章或寻找社交账号。用户已选择人文巨字与字符姓名，要求保留蓝色、鼠标局部避让及强动态表现。当前轮不重新开风格卡片。

“克制”在本轮指白纸黑字、蓝色占首屏约 10% 以下，除了姓名与目录预览不再加独立装饰特效。“高级”指清晰的尺度差、真实内容、统一运动节奏与键盘/触屏等价操作，不靠灰色低对比大字。

字体采用本地 Satoshi 500/700、Georgia 人文斜体、Menlo 字符。中文下一轮再验证思源宋体，不把英文验收作为中文通过。

## 标杆与实际实现

参考用户提供的 Ansyn 与 JIEJOE 截图，也读取了公开页面源码。Ansyn 的目录预览是独立 fixed 层、指针缓动跟随、边缘避让、缩放与旋转出现；聚焦可预览，滚动离开当前行会隐藏。JIEJOE 的目录预览跟随鼠标，进入放大、离开缩小，切换条目时重新旋入。保留“文字先行、图片按需出现”，不搬个人信息、头像、地球或绿黑配色，不复用对方授权字体。

公开来源：https://ansyn.me/；https://www.jiejoe.com/home。
Ansyn 的参考取证位于相邻 `reference-motion/ansyn/`：行为可见，但远端图片加载异常，不能作为完整画面基线。

## 01 · 姓名星座

- 北极星：像一张打开的个人扉页，先记住姓名，再选择进入哪个内容世界。
- 调性：中等能量、精致、疏密交替、姓名重而目录轻、人文而非庄重。
- 引擎：人文扉页与字符编码并置。兴趣词是语义前景，不是低对比背景。
- 首屏：顶栏 8%，中间字符姓名约 50%，周围错落的兴趣词约 15%，底部真实身份和作品入口。无图卡、无营销口号。
- 下半页：WORK / WRITING / ABOUT 三个大字分类入口；展开目录时显示真实名称、说明及图片。结尾不重复一段口号。
- 色彩：#FCFCFC 纸面，#181818 字与线，#2456D6 蓝色语义词/交互，#D97757 仅用于 History，#626262 次要信息。
- 图标：本地 Lucide 的向下箭头与关闭符号；展开用向下，不假装外链。
- 控件：整行是展开按钮、0 圆角、细线边界、按下缩至 .99；点击即时更新状态，图片与内容 280ms 展开。
- 动效：字符 550ms 聚集；指针附近蓝色字符轻轻避让；滚动 0–620px 姓名压实并缩入顶栏，主题词向外让路；目录按行从左侧进入，页脚线条水平展开；浮图进入缩放/倾斜、移动有阻尼、切行重置图像姿态、离开快于进入。
- 结构突破：不把作品变成首屏卡片，姓名与兴趣词组成全幅扉页；下一节用分类层组织内容。
- 放弃：常驻头图、三个灰色背景巨字、三个功能卡、无意义数字。

## 02 · 排字带 / 直接索引

- 北极星：从姓名直接翻到作品清单，让作者的兴趣成为翻页时的排字节奏。
- 调性与字体同已选风格，结构更直接、更密。兴趣带占据独立横向区域，而非环绕姓名。
- 引擎：出版物的版心与排字带。姓名在上方，Tech / Life / History 横向交错，作品索引紧接首屏。
- 首屏：顶栏 8%，字符姓名约 48%，通栏兴趣排字带约 20%，身份与项目入口约 15%；首屏露作品区起点。
- 下半页：直接列 Dayline Journal 与 Haoo Blog；黑底文章区使用衬线标题与日期，形成白/黑章节交接；页脚直接展示社交身份。
- 色彩：同一白黑蓝色板，蓝色主要承担 Life 与索引编号；文章段正反色，不把整页变成蓝色。
- 控件：作品行整项展开，文章行为标题与日期双列；行内图片默认收起，触屏点击也可查看；无第二层分类。
- 动效：字符聚集与避让同品牌组件；滚动 0–600px 字符姓名压实并收进导航，排字带 Tech 向左、History 向右拉开；作品细线从左展开，文章标题由遮罩向上揭出；浮图进入短促旋入、切行再旋入，离开缩回。
- 结构突破：主题词不浮在姓名周围，而是可被滚动拆开的排字带；项目先行，不必先选 WORK。
- 放弃：ABOUT 大分类、作品常驻卡片、每节重复副标题。

## 状态与设备

- 默认无 JavaScript 仍显示姓名、标题与内容结构；Canvas 成功后才隐藏实心姓名。
- 鼠标可浮出预览；键盘 focus 同样可预览；Esc 收回并保持当前位置。
- 窄屏不显示指针跟随图，点击行展开原位图与说明，不接管触屏滚动。
- 字体就绪与可见尺寸就绪后构建字符；隐藏预览挂载后通过 ResizeObserver 等待真实尺寸。
- 减少动态效果时取消收字与位移，内容直接到位；`?motion=reduce` 可用于同样的检查分支。
- `?state=work` / `writing` / `about`（01）与 `?state=dayline` / `blog` / `ai` / `kindle`（02）可直接检查展开状态。

## 07 · 字标交接与悬停深化

上一轮“收进导航”的结论不成立：绝对定位字标仍随文档滚动，缩小后继续离开视口；旧回归测试也没有覆盖当前英文模块。此次改为同一个 fixed 字标，从 Hero 文档坐标出发，按顶栏 dock 的实际尺寸与中心缩入，完整留在导航；反向滚动恢复巨字，刷新和窗口变化重新测量。

索引悬停选择黑白反转与一次短暂字符化，不叠加宋体切换。黑底从下方铺开，白色标题由 `01{}<>/` 组成，700ms 内恢复实心字；持续停留维持黑底和清晰标题，不循环闪烁。键盘聚焦同等呈现，离开快速回收；减少动态效果保留直接反转，不播放字符变化。橙色仍只给 History，蓝色仍保留在姓名句点。

展开状态移除旧 inline onclick 与额外 DOM 切换监听，只由 Alpine 管理，展开/收起后刷新 ScrollTrigger 的真实布局。
