# Haoo Blog 前端设计快照说明

生成方式：draw-ui skill 流程 + imagegen relay（`gpt-image-2.5`，quality high）。
事实源：`REBUILD-BRIEF.md`（前端方向）+ `DESIGN-v2-draft.md`（已 lint 的 token）。

## 目标与范围

- 用户任务：访客 3 秒内认清「这是 Haoo 的个人博客」，并顺着编号列表进入文章。
- 页面范围：桌面首页完整长页（导航 → Hero → 编号列表 → 页脚）、首页首屏、文章页、移动端首页。
- 交付方式：只要设计稿（快照）与实现说明，不写代码。
- 现有约束：框架 Astro、亮色为默认主视角、accent 蓝 `#2E6FA8`、字体 Satoshi + Instrument Serif Italic、首页门面炫 / 文章页静。

## 视觉构思

- 主要手法「墨字双声部」：云白底上拉满对比度的墨色巨字，实心无衬线（TECH）与描边无衬线（HISTORY）交替，衬线斜体蓝色的 LIFE 是呼吸点；四个词同级同尺寸，不设主次。
- 第一眼焦点：首屏 80% 被 slogan 占据；Canvas 文字特效只留定格痕——描边字右缘的稀疏墨蓝颗粒，不发光、不成块。
- 延续方式：衬线斜体与强调蓝在首页只出现在 LIFE、悬挂编号、蓝色印章三处；文章页延续同一字体体系但去掉全部动效语言。
- 编辑部标记：竖排中文年份「二〇二六」+ 蓝色方章落款，放在 Hero 右栏留白。

## 结构与规则

- 内容顺序：导航（Haoo｜文章 项目 记录 关于｜主题切换）→ Hero（slogan + 竖排年份 + 印章 + 一句话态度）→ 编号列表（01/02，标题单行截断，日期右对齐）→ 页脚（© 2026 Haoo｜邮箱｜社交）。
- 对齐基准：内容最大宽度 1120px，移动 gutter 24px；首页大字左对齐，编号悬挂在左栏——至少一处打破对称。
- 颜色：底 `#F6F8F8`、墨 `#14253A`、雾蓝灰 `#55708C`、accent `#2E6FA8`、分割线 `#D9E1E8`；暗色底 `#0B1220`、字 `#E8F1F6`、accent `#8FC8ED`。强调蓝占比 <5%。
- 字号：display 4.5rem（两族同级）、body 1rem、meta 0.75rem（字距 0.08em）。
- 禁止：渐变、光晕、玻璃拟态、紫色、暖橙、荧光绿、图标瓷砖卡片、全部居中、装饰性强调色。

## 素材

- 首页零摄影素材：全部由排版、线条、Canvas 定格颗粒构成。
- 文章页如需配图，只使用真实文章内的实拍图容器，不用生成的插画填充。
- 本轮快照不产出独立位图素材；印章与颗粒属于视觉符号，实现时用 CSS/SVG/Canvas 绘制。

## 内容变化与待验证

- 长标题：列表标题单行截断，窄屏两行后截断。
- 更多文章：列表随数量向下生长，编号保持两位数递增。
- 窄屏：slogan 降为两行、编号悬挂改内联前置。
- 待验证（未在快照内证明）：真实交互、响应式断点、Canvas 特效运行效果、无衬线/衬线中文字重回退表现。
